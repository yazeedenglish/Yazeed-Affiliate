نظام شركاء Yazeed English — نسخة أولية ثابتة
============================================

المتطلبات
---------
HTML + CSS + JavaScript + JSON فقط. لا توجد قاعدة بيانات أو Backend.

التشغيل
-------
1. ارفع مجلد yazeed-affiliate كاملًا إلى استضافة الموقع الثابت.
2. افتح المسار /login/.
3. بيانات التجربة:
   رمز الشريك: PARTNER001
   كلمة المرور: AB123456
4. يجب تشغيله عبر استضافة أو خادم محلي يدعم fetch. فتح login/index.html مباشرة عبر file:// قد يمنع قراءة JSON.

الملفات المهمة
--------------
- login/index.html: صفحة تسجيل الدخول.
- dashboard/index.html: لوحة الشريك.
- css/style.css: تصميم متناسق مع متغيرات Yazeed English.
- js/login.js: منطق تسجيل الدخول.
- js/dashboard.js: عرض الطلبات والحوالات وحساب الإحصائيات.
- data/affiliates/PARTNER001.json: ملف بيانات الشريك التجريبي.
- pages/support.html: دعم الشركاء.
- pages/faq.html: الأسئلة الشائعة.
- pages/policy.html: سياسة الشركاء.

إضافة شريك جديد
---------------
1. انسخ PARTNER001.json إلى ملف جديد اسمه رمز الشريك تمامًا، مثل ALI2026.json.
2. غيّر قيمة code لتطابق اسم الملف ورمز الشريك.
3. ضع كلمة مرور من 8 أحرف بالضبط، واسم الشريك، والطلبات والحوالات.
4. لا تضع مسافات أو أحرفًا غير A-Z أو 0-9 أو الشرطة - أو _ في رمز الشريك.

إضافة طلب
---------
أضف عنصرًا داخل مصفوفة orders في ملف الشريك، مثال:
{
  "id": "ORDER-003",
  "product": "اسم المنتج",
  "addedAt": "2026-10-01T15:00:00+03:00",
  "commission": 10,
  "status": "approved"
}

- يبدأ احتساب مهلة الضمان من addedAt.
- بعد 15 يومًا كاملة يظهر الطلب وتدخل عمولته في الرصيد.
- إذا استُرجع الطلب خلال الضمان، غيّر status إلى "refunded" وأضف refundedAt بتاريخ ووقت الاسترجاع، مثال: "2026-10-10T12:00:00+03:00". سيظل الطلب مستبعدًا من العمولات.
- إذا سُجل الاسترجاع بعد انتهاء الضمان، فلن يُعكس الاستحقاق تلقائيًا؛ تاريخ refundedAt بعد موعد انتهاء الضمان يحافظ على العمولة.
- status بقيمة "approved" لا تعني أن الطلب ظهر فورًا؛ يجب أن تنتهي مهلة الضمان أيضًا.

تسجيل حوالة
------------
أضف عنصرًا داخل مصفوفة transfers، مثال:
{
  "date": "2026-10-15",
  "amount": 50
}

مهم: هذه النسخة تخصم مجموع الحوالات من مجموع عمولات الطلبات المؤهلة للظهور. لا تربط الحوالة بطلبات محددة، وفق القرار المعتمد. لا تسجل الحوالة أكثر من مرة.

تنبيهات مهمة
------------
- لا تعدّل ملف JSON أثناء استخدام الشريك للوحة ثم تتوقع أن يتغير تلقائيًا دون إعادة تحميل الصفحة.
- ملفات JSON المنشورة يمكن تنزيلها، والتحقق من الدخول في JavaScript ليس مصادقة آمنة حقيقية.
- لا تستخدم هذه النسخة لتخزين بيانات حساسة.
- المثال يتضمن طلبًا قديمًا مؤهلًا للظهور وطلبًا حديثًا سيظل مخفيًا حتى مرور 15 يومًا من وقت إضافته.
- الاسترجاع بعد انتهاء الضمان لا يلغي العمولة تلقائيًا إذا سُجل refundedAt بعد موعد انتهاء الضمان. احرص على تسجيل تاريخ الاسترجاع الصحيح.
